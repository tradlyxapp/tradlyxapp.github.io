# tradlyx.app

The home page and privacy policy for tradlyx.app and its apps (Tradlyx at stocks.tradlyx.app, Household at
household.tradlyx.app), served by GitHub Pages from `main` (the `CNAME` file sets the domain).

- `index.html`: what Tradlyx is and the apps.
- `privacy.html`: one policy for the site and both apps. Household's full policy, the one Google's review
  reads, lives with Household (`missions/site/`, published at tradlyxapp.github.io/household-reminders); keep
  this page's Household section a summary that links to it.

Change a page when what an app keeps or which services it uses changes, and move the "Effective" date with it.
